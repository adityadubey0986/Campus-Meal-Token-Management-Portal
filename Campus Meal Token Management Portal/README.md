# MealFlow - LPU Campus Canteen

## How to run
1. Extract the ZIP file.
2. Keep index.html, style.css, and script.js together in one folder.
3. Open index.html in a web browser.

## Files
- index.html: Website structure and content.
- style.css: Colors, layout, images, and responsive styling.
- script.js: Search, filters, order booking, price calculation, waiting time, and token cancellation.

Food photos and campus photos use online image links, so internet access is needed to display them. Bookings are saved in this browser only.
